# AlpaSim E2E Closed Loop Challenge 2026 — nuPlan Track

Camera-only end-to-end driving policy built on ReCogDrive (VLM + diffusion planner), extended with
eight-camera input and an occupancy world model that predicts future 3D occupancy for the planner.

The technical report and related materials will be released here after the challenge closes
(November 2026).
